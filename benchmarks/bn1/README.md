# BN1 bridge diagnostic

[`initial-bridge-diagnostic-linux-x64.json`](initial-bridge-diagnostic-linux-x64.json)
keeps the summary measurements of the first Linux x64 bridge diagnostic. It used a
development-profile host, before the committed runner kept per-request samples.
It is not a release baseline or a controlled comparison.

[`BRIDGE.md`](../BRIDGE.md#initial-diagnostic-findings) explains these numbers and
gives the current `bun benchmarks/bridge.ts` commands for development and AOT runs.
