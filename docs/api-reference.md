# Public API reference

This page lists every export of the three application packages: `@bun-native/core`, `@bun-native/solid` and `@bun-native/react`. Each row links to the page that specifies the behavior. The packages are experimental, private to this checkout (or a [standalone package set](standalone-projects.md)) and carry no stability promise; see the [compatibility matrix](compatibility.md) for the release each row describes. `@bun-native/protocol`, `@bun-native/runtime` and `@bun-native/renderer` are internal layers: applications use them only through the exports below.

[`tests/quality/api-reference.test.ts`](../tests/quality/api-reference.test.ts) fails when a package export is missing from this page or a name in a table here is no longer exported.
